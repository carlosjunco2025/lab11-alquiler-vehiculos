¿Cómo funciona este panel?

El frontend se sirve desde ms-alquiler y consume las tres APIs REST. Al registrar un alquiler, el servicio valida el cliente, comprueba la disponibilidad del vehículo, calcula el importe y cambia el estado del vehículo a ALQUILADO.
